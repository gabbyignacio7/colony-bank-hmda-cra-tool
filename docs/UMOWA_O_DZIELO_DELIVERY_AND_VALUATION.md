# Umowa o Dzieło — Zasady dostaw kodu i wyceny  
## Code delivery and valuation rules (Contract for specific work)

**Project:** Colony Bank HMDA/CRA ETL Automation Tool  
**Document version:** 1.0  
**Last updated:** February 2025  

---

## 1. Scope and assignment of rights

All code created under **Umowa o Dzieło** (contract for specific work) must be **assigned to the company**. The contractor transfers full copyright and related rights to the company upon delivery and payment.

---

## 2. Delivery format

- Code must be delivered in **DOCX** or **PDF** format.
- The delivered file(s) must contain the actual source code (not only screenshots or summaries), formatted so that page count can be verified.

---

## 3. Valuation rule

| Rule | Value |
|------|--------|
| **1 page of code** | **2,000 PLN gross** |

Valuation is based on the number of pages of code delivered, at a fixed rate of 2,000 PLN gross per page.

---

## 4. Withdrawal rule

The gross withdrawal amount determines how many pages of code must be delivered:

**Formula:**

$$\text{Number of code pages} = \frac{\text{Withdrawal amount (PLN gross)}}{2{,}000}$$

**Examples:**

| Withdrawal (PLN gross) | Required code pages |
|------------------------|----------------------|
| 20,000 | 10 |
| 10,000 | 5 |
| 27,000 | 13.5 → **14 pages** (round up to fulfil withdrawal) |

*Note: Contractor reference salary is circa 27,000 PLN; the same valuation rule applies to withdrawals under Umowa o Dzieło.*

---

## 5. Documentation requirements

Each code delivery must be accompanied by a **separate short description document**.

The description must clearly state:

1. **Programming language(s)** used in the delivered code (e.g. TypeScript, Python).
2. **Functionality / purpose of the code** (what the code does, which module or feature it implements, and how it fits into the project).

The description can be brief (e.g. one page) but must be submitted as a **separate** document alongside the code file(s).

---

## 6. Example delivery (20,000 PLN gross)

- **Withdrawal:** 20,000 PLN gross  
- **Delivery:**
  - **10 pages of code** (in DOCX or PDF), and  
  - **1 separate short description** covering:
    - programming language(s), and  
    - functionality / purpose of the delivered code  

---

## 7. Checklist for each delivery

- [ ] Code delivered in **DOCX** or **PDF**
- [ ] **Page count** matches: Withdrawal (PLN gross) ÷ 2,000 (rounded as agreed)
- [ ] **Separate description document** attached
- [ ] Description states **programming language(s)**
- [ ] Description states **functionality / purpose** of the code
- [ ] Rights to the code **assigned to the company** as per Umowa o Dzieło
